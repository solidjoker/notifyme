TodayToTomorrow for little mermaid

一个本地优先的微信通知捕获、会话管理与 AI 分析工具。通知原文留在你自己的设备上，分析用你自己指定的模型，需要行动的消息自动生成日历 / 闹钟提醒。

AndroidMIT Licensev0.3.0本地优先 · 离线可用

下载 APK GitHub

核心功能

通知原文不出设备 · 分析模型自选 · 提醒自动触达

多应用通知捕获

  • 通知监听 + 无障碍直读双通道
  • 支持微信 / 飞书 / 钉钉等多应用
  • 来源白名单，精确控制采集范围
  • 按「会话-日期」两级分组折叠
  • 左滑删除 / 长按批量删除

两阶段 AI 分析

  • System 1 轻量快筛：是否需要行动
  • System 2 深度分析：拆解任务/截止/建议
  • ⚡ 角标标记待行动结果
  • 每会话独立自定义提示词
  • 支持端侧模型推理（离线可用）

三级降级提醒

  • 系统日历事件直写（含提前提醒）
  • 日历 App 预填唤起
  • App 内闹钟通知兜底
  • 日历角标 + 提醒管理页
  • 按 caseId 智能去重

隐私保护

  • 通知原文不出设备
  • 三级脱敏（规则/白名单/预览）
  • 云端分析自动脱敏后发送
  • 数据仅存 App 私有目录

悬浮通知 + 待办面板

  • 悬浮球常驻，一键展开待办面板
  • 重要消息悬浮卡（标记已处理/详情）
  • ⚡ 角标 + 任务计数
  • 与主页数据实时联动

可选服务端同步

  • 自托管 Flask 服务端
  • 跨设备 PWA 查看端
  • 历史回填（安卓/PC 微信数据库）
  • WorkManager 可靠调度
