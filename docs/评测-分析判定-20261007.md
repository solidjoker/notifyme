## 三·补遗（2026-10-07 晚间，S2 修复后完整闭环）

- **S2 根因勘误**：GLM 401 并非密钥失效——是评测脚本提取密钥时 `Substring` 少切一位留下前导 `=`。正确提取后 PC 直测 HTTP 200。
- **修复后真机完整闭环实测**（真实微信班级群通知「陈老师：@所有人 明天正常训练 16:30-17:30 明德校区体育馆」）：
  - S1 = Laya jev-1.13.0（云端）：need_action noul=0.78 → true，escalate split ✅
  - S2 = GLM glm-5.3-flash（云端）：HTTP 200，输出 summary「合唱团明天16:30明德体育馆正常训练」+ due_time「明天16:30」+ suggested_action + tasks[我/带孩子按时到明德校区体育馆/明天16:30]（含 reasoning_content）✅
  - ⚡1 待办角标（橙底）出现在会话头 ✅；待办条「截止：明天16:30」✅
  - **真实悬浮卡弹出**（卡片+标记已处理/打开详情按钮，5s 自消）✅
- **端侧 0.5B 对照结论维持**：回显占位符不可当主判定，仅离线兜底。
- 教训：密钥类字符串做 Substring 提取时偏移量必须用实测长度验证（本次 401 与「密钥失效」误判均为提取偏移导致）。
